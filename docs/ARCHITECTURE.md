# Employee mobile architecture
Expo Router app routes in `app/`; features in `src/features/auth`, `src/features/shifts`, `src/features/calls`, `src/features/notifications`; shared `src/shared/ui`, `src/shared/api`, `src/shared/mock`, `src/shared/config`. UI -> feature hooks -> typed application ports -> infrastructure adapters. Persist tokens in expo-secure-store. Notifications use Expo push tokens with server registration, foreground realtime with reconnect/backfill and OS-supported distinct sounds. Shift ownership server-side; do not rely on device time for shift policy. No accept/complete flow. Independent mock state.
